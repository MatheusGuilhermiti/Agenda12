# Meus Sites Favoritos

Atividade Ag12 - Desenvolvimento de Sistemas I

## Sobre o projeto

Este projeto foi desenvolvido para uma atividade da ETEC. O objetivo é criar uma página web com meus cinco sites favoritos, mostrando o nome, a imagem e um link para acessar cada site.

## Sites utilizados

- Google
- YouTube
- TikTok
- Roblox
- Discord

## Tecnologias utilizadas

- HTML
- CSS

## Como executar

1. Baixe ou extraia a pasta do projeto.
2. Verifique se a pasta `logos` contém todas as imagens utilizadas.
3. Abra o arquivo `index.html` em um navegador.
4. Clique nos links para acessar os sites.
